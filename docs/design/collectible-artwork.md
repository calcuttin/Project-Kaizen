# Collectible artwork refresh

Generated and edited with the built-in Image Generation tool. Final assets are bundled in `public/library/objects/`; the app does not call an image service. The six new collectibles use black-backed source photography. A runtime SVG color-matrix filter derives edge alpha from the black background while retaining solid RGB materials; this replaces the previous screen blend that showed wood grain through objects. Dragon and bust use sibling `-v2.png` assets so the originals remain available.

Use case: product-mockup. Production collectible asset for a photorealistic walnut library display cabinet. Genuinely transparent alpha background, no room, no floor, no backdrop, no baked-in cast shadow, no text, no watermark.
